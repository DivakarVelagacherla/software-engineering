# Designs

Real system designs practiced for interviews, and how to talk through them out loud — this is
where `basics/` and `advanced/` get put into practice.

Convention: one markdown file per design (e.g. `url-shortener.md`), with any diagrams
(draw.io exports) placed alongside it in this same flat folder, matching the design's filename
(e.g. `url-shortener.png`) and referenced from the markdown with a normal image link.
