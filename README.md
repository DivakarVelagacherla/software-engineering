# Software Engineering Notes

Divakar's personal notes and books on software engineering — system design, languages, and
frameworks. This repo is the content source for the "Learning" section of
[the portfolio site](https://github.com/DivakarVelagacherla/portfolio): new material committed
here is meant to surface there automatically, so structure and naming stay consistent across
topics on purpose. See `CLAUDE.md` for the conventions that make that possible.

## Contents

- **[`internals-of-core-java/`](./internals-of-core-java/)** — *Internals of Core Java*, a book on how the language and JVM actually work.
- **[`everything-about-spring-and-spring-boot/`](./everything-about-spring-and-spring-boot/)** — *Everything About Spring and Spring Boot*, the framework layer built on top of it.
- **[`system-design/`](./system-design/)** — Tiered notes on system design fundamentals, databases, architectural patterns, and reliability.

Each folder has its own `README.md` with a table of contents for that topic.
